在 Windows 上用 iTunes 或 Apple Music 听 Book2Audio GO 有声书

用 Book2Audio GO 将电子书转换为 MP3 后，就可以把生成的章节添加到 iTunes 或 Windows 版 Apple Music 的资料库。

1. 打开书籍的音频文件夹

在 Book2Audio GO 左侧打开 Library，将鼠标移到书籍封面上，点击 Open Audio Folder。如果要导入整本书，先等所有章节转换完成。

2. 复制文件夹路径

在打开的文件资源管理器中，按 Ctrl + L 选中地址栏，再按 Ctrl + C 复制路径。下方会列出已经生成的 MP3 章节。

3. 将 MP3 添加到 iTunes 资料库

在 Windows 版 iTunes 中，点击 文件 → 将文件添加到资料库，也可以按 Ctrl + O。在弹出的窗口中点击地址栏，粘贴刚复制的路径并按回车。选中想听的 MP3，然后点击 打开。

如果要一次导入整本书，可选择 文件 → 将文件夹添加到资料库，然后选中该书的 audio 文件夹。

4. 在资料库中找到书籍并播放

导入后，在 iTunes 资料库的 最近添加 中找书籍封面，也可以用顶部的搜索框搜索书名。点击封面展开曲目，再双击想听的章节。截图示例只导入了一个章节，所以列表中只有一条曲目。

使用 Windows 版 Apple Music 播放

如果你使用的是独立的 Apple Music App，打开边栏顶部的操作菜单，选择 导入，再选择同一个 MP3 文件或整个 audio 文件夹。导入后，在 资料库 → 最近添加 或 专辑 中找到这本书，打开后选择章节播放。Apple 官方导入说明

如果还想在 iPhone 或 iPad 上通过 Apple Music 播放，可以将 MP3 作为音乐曲目导入，再使用同一个已订阅 Apple Music 的账户，在电脑和移动设备上打开 同步资料库。使用 iTunes 时，这个选项叫 iCloud 音乐资料库。同步完成后，在移动设备的 Apple Music 资料库中按书名查找。Apple 官方同步说明
